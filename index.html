Quick actions

Important limitation: this Android rebuild does not connect to MT5 desktop, fetch live HFM account balances, read open positions, or send broker orders. It is a manual analysis and planning tool. Use the HFM MT5 app separately to verify prices and place trades.

Manual trade workflow

  1. Check the instrument and current quote in HFM MT5.
  2. Enter completed candle data in the ICT Scanner, or plan a trade manually.
  3. Calculate position size and risk.
  4. Verify entry, stop-loss, take-profit, spread and margin in MT5.
  5. Place the trade yourself in MT5, then record it in the journal.

ICT Entry / Exit Scanner

Rule-based approximation of the source project's ICT concepts. It requires completed candles entered by you; it does not download live candles.

Concept checklist

The scanner evaluates swing highs/lows, liquidity sweeps, three-candle FVGs, volume/gap imbalances, basic order-block candidates, AMD range sweeps, premium/discount and a New York killzone reference. It is a simplified mobile port, not a byte-for-byte copy of the Python engine.

Settings & help

HFM account connection

Use the official HFM MT5 Android app for login, live prices, account balance, positions and trade execution. This companion intentionally does not ask for or store your HFM password.

Install on Android

After this app is published to a secure HTTPS address, open it in Chrome, tap the three-dot menu, then choose Install app or Add to Home screen.

PWA installation requires secure hosting (HTTPS) for a normal website deployment.
